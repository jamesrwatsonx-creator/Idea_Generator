# Build sequence

1. V1 foundation: ten modes, source catalog, prompt compiler, plans, capture/import, declared gates and explicit provider calls.
2. Catalog adapters: query Maliky and Every Awesome Repo, preserve asset IDs/revisions and provenance.
3. Verified research: selected API/browser/scraper adapter, source permissions, freshness, failures and claim-to-excerpt checking.
4. Durable engine: run state, call/spend ledger, cancellation, resume, duplicate detection and history-based novelty.
5. Jev evaluation: representative positives, negatives, hard cases, human labels and held-out examples. Tune atomic questions; measure false negatives.
6. OpenRouter workflow: structured candidates, independent critique, retry/error semantics and evidence validation.
7. Dashboard: three entry choices, ten methods, evidence-backed cards, depth actions; server-only keys.
8. Outcome loop: experiments, abandon conditions, actual results and measured decision quality.

No phase is complete merely because it is documented. Registry entries remain unconnected until adapters and live checks establish otherwise.
