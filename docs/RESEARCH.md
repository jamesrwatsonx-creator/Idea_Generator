# Evidence, not report volume

NoSignups is a primary discovery source. A directory is not primary evidence of purchasing. Our World in Data is structural context; trace original data and methodology. Keep demand, macro need and feasibility separate.

Record prevalence, frequency, consequences, current response, dissatisfaction, actionability, buyer access and evidence quality separately. Identify source population, geography, collection period and denominator. Do not add raw review counts across unrelated sites, count syndicated claims as independent, or infer paid demand from stars, votes or traffic.

Evidence status: captured_unreviewed / reviewed_claim / behavior_reported / behavior_observed. These are claim-specific, not a universal verification badge. Source registry evidence_status only describes the initial source inspection; connector_status describes implementation separately.

## Test methods
| Method | Establishes | Leaves unresolved |
|---|---|---|
| Interview | Prior workflow, vocabulary and constraints | Purchase of the proposed offer |
| Sample | Relevance and interpretation | Repeat use and payment |
| Landing page | Response to offer/channel | Delivery and retention |
| Paid manual pilot | Initial purchase/outcome | Automation economics |
| Repeated paid use | Early recurring value | Broader market size |
| Automated pilot | Operating reliability/cost | Durable acquisition |

Five roles: experiences / understands / evaluates / authorizes / changes behavior. An understood cost does not create authority or eliminate switching friction. Estimated avoided loss, revenue captured and contribution margin must remain separate.

Before an experiment: falsifiable claim, qualified sample/exposure, measurement, currency, deadline, spending limit and abandon condition. Stop conditions are mandatory; evidence-based reopening is allowed. Unknown blocks advancement without pretending to disprove the market. User-provided original five prompts are the conceptual starting point; current method files are edited implementations, not claimed verbatim copies.
