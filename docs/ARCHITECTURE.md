# Architecture and boundaries

Ten discovery methods share constitution, records and gates. Separate landscape discovery, candidate investigation and behavioral validation. A research report cannot manufacture purchase evidence.

Market/structural records and capability records are distinct. Every Awesome Repo supplies external leads; Maliky supplies available assets with provenance. Fetch their catalog interfaces rather than duplicating their databases. Current source registry links them; V1 does not sync their catalogs.

Acquisition candidates: documented API/download/catalog → Markdown extraction → browser interaction or scraper for justified gaps. Selection is explicit and source-specific, not a universal fallback that bypasses restrictions.

V1 implementation:
- Local searchable registry and ten compiled method prompts.
- Deterministic random research directions and bounded plans.
- Single public URL capture through markdown.new, with .md + metadata JSON.
- Import browser/scraper/manual Markdown captures.
- Single-call OpenRouter synthesis and optional TypeSafe SDK screening (not live-validated).
- Deterministic gates for declared evidence references. They do not authenticate citations or assess whether evidence supports a claim.

Future integration contract: acquire(query/URL, limits, permissions) -> captures + source metadata + failures + usage. Every adapter must distinguish error, empty result, blocked, partial and complete. Store requested and final URLs, original publication/source group, retrieval time, content hash, extractor version and completeness. Future crawler must validate redirects and block private networks at connection time; V1 third-party public-URL converter is not a general SSRF-safe fetch proxy.

Jev supplies bounded judgments. Code combines those with explicit rules. OpenRouter models plan and synthesize. Browser/scraper tools actually acquire information. Scores/probabilities do not become facts. Escalate uncertain/high-impact judgments instead of hiding them.

No autonomous browser jobs, third-party crawling, paid Apify runs, cross-provider loops or scheduled work are active. Add durable runs, approved-source retrieval, budget accounting, cancellation and verified model outputs before enabling autonomous research. V1 caps per-call input/output and has plan page/call limits; it does not enforce a monetary budget across runs. Configure provider-side spend caps before use.
