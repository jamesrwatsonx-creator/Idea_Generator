# Simple entry, optional depth

Home: **Surprise me / Start with something / Explore all methods**. Optional focus input. Advanced preferences retain budget, geography, outreach tolerance and connected sources. No key entry in public client code.

Start with something accepts an app, repo, workflow, dataset or rough idea. Show the interpreted method and allow correction. All ten methods remain directly accessible.

Surprise me is first-class, not a fallback. Seeded selection chooses a person/situation/lens; the resulting research may return no survivors. Preserve history and diversify future directions. V1 seeded plans do not yet use investigation history.

Research activity shows short status, stop, budget/request counters and expandable source details. Stopping acquisition does not discard prior evidence. Only future durable job execution can promise cancellation mid-request; V1 CLI is single-action.

Idea card: idea / person / consequence / evidence / unknown. Actions: Go deeper, variation, combine, save, pass. Depth directions: Demand / Product / Build / Challenge / Test. Research depth is bounded and does not automatically raise spending limits.

Do not show a fake completed research report while the backend only has a plan. V1 ships the research foundation and CLI; the dashboard is the next surface, not implemented yet.
