# Exploit a recent change

## Entry point
Find newly viable offers and migration needs.
A seed is optional. If absent, select and disclose a bounded research direction.

## Method-specific investigation
1. Verify the dated change and identify affected users; never invent a retirement date.
2. Describe the former constraint and how the change alters a workflow or economics.
3. Estimate the window as a scenario, not a fact; identify what closes it and how customers can be reached.

## Execute
First decompose the situation and identify assumptions. Create a bounded search plan using the source registry. Acquire source material through permitted adapters. If tools or credentials are unavailable, name the missing evidence and return a research plan, not a fabricated result. Generate up to twelve distinct candidates without padding; examine each against the shared gates, stopping at the first failure or evidence gap. A survivor count of zero is valid.

Keep the five conversion roles visible: experiences, understands, evaluates, authorizes, changes behavior. Determine whether customer, product, or intermediary interprets the consequence. Show the number first when it is defensible and decision-relevant; otherwise name and test the observable signal replacing it.

## Required output
1. Input decomposition and research scope.
2. Evidence table with IDs, URLs, excerpts, observation dates, provenance groups, limitations and listed/reported/observed labels.
3. Candidate map, including the current alternative and mechanism of value.
4. Kill log: candidate, first failed gate, reason and reopening evidence. Do not fabricate failures to make this section longer.
5. Survivors: customer, consequence, buyer roles, sources/capabilities, missing pieces, channel, economics and experiment.
6. One next experiment, with falsifiable claim, qualified audience, measurement, spending/time limits and precommitted abandon condition.
7. Strongest rival explanation; evidence that reverses the recommendation.

## Go deeper
Offer Demand / Product / Build / Challenge / Test. Preserve the same investigation and evidence IDs. Additional research must address a named uncertainty and respect the page/call limits; do not silently expand scope.
